# 本机导入

在 Navicat 用自己的 MySQL 8.4 管理员账号连接本机，创建一个空数据库。在同一个数据库下先运行 `schema.sql`，再运行 `seed.sql`。旧版项目表的列较多，建表脚本会临时调整当前连接的 InnoDB 严格模式，建表后恢复。

导入后应有 7 个项目、6 个点位、11 条公司记录和 8 条部门记录。

需要接入已授权的萤石设备时，在同一数据库运行单独交接的 `private/camera.local.sql`。它包含真机参数，按私下渠道交接。也可以用 `camera.example.sql` 填入自己有权限的设备参数。

四张表覆盖项目和摄像头的业务数据。现有整站的登录与权限服务依赖额外的数据或服务。
